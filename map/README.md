# Updated world map

The map uses the newly supplied 1651 × 953 image with the same SVG viewBox and aspect ratio. Fourteen selection shapes trace visible coasts and political boundaries. Thirty-five records position named cities, countries and landmarks against the printed dots. Country borders absent from the source are not invented.

Upload this entire map directory, including assets. The HTML embeds the same paths as assets/region-outlines.svg. Zoom, pan, keyboard selection and click descriptions are retained. Named markers include Whale Island, Trick Tower, Zevil Island, Swardani City and Kakin Royal Capital.
